# Детализированная дорожная карта разработки: Doctor Lab (DL)

Этот документ описывает подробный, гранулярный план разработки продукта "Doctor Lab". Каждый этап разбит на конкретные подзадачи для бэкенда (BE) и фронтенда (FE).
