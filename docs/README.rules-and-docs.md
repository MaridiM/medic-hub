# Cursor Rules & Docs — How to Use

## Where
- Project rules live in `.cursor/rules/*` (Markdown with front-matter).
- Documentation lives in `docs/*`.

## How
- In Cursor chat, add `@Cursor Rules` and select relevant rule files.
- Add `@Folders docs` or `@Files docs/api-contracts.md` to feed domain docs.

## Tips
- Keep rules short and specific; add code examples.
- Update ADRs when making architectural decisions.
