### 2025-09-21 (Feature)

*   **Действие:** Реализация страницы онбординга "Создание Специалиста/Организации".
*   **Комментарий:** В соответствии с предоставленным ТЗ, была создана новая страница по адресу `/create-organization`. Эта страница представляет собой многошаговый процесс для сбора данных.
    *   **Структура:** Фича полностью инкапсулирована в директории `apps/web/src/app/(onboarding)/create-organization/`.
    *   **Шаги:** Реализованы все 3 шага: выбор режима, выбор типа организации и основная форма для ввода данных.
    *   **Формы и Валидация:** Для управления состоянием формы используется `react-hook-form`, а для валидации — `zod`. Схемы валидации динамически применяются в зависимости от выбора пользователя.
    *   **Компоненты:** Создан набор переиспользуемых компонентов, включая `Stepper`, `ChoiceCard`, и кастомные элементы формы (`FormInput`, `FormSelectSearchable`, `FormMultiSelectSearchable`), интегрированные с `react-hook-form`.
    *   **Зависимая логика:** Реализована логика, при которой выбор региона автоматически устанавливает страну, а смена страны сбрасывает поле города.
    *   **Итог:** При успешном заполнении формы, в консоль выводится `payload` с собранными данными и появляется `alert` об успешном сохранении черновика.
